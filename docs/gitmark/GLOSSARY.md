# Термины общего агента

Одна область контекста — исследование типизированных решений сервисного агента.
Определения уточнены по согласованным направлениям команды 11.10.2026;
семейства моделей описаны в [постановке](research.md#термины-и-кандидаты-моделей).
Термины человеческой проверки разметки добавлены по обсуждению 24.10.2026.

## Язык исследования

**Маршрутизация решения:** выбор, доверить ли решение компактной модели
или передать его генеративной LLM, с учётом риска и стоимости.
_Не смешивать с_: выбором операции, выбором способа поиска.

**Маршрутизация отбора контекста:** выбор, принять ли набор контекста, предложенный
компактным методом, или поручить тот же отбор генеративной LLM.
_Не смешивать с_: выбором генеративной модели для всего шага агента, выбором tools.

**Выбор операции:** определение того, что агент должен сделать следующим
в наблюдаемом состоянии; само по себе не включает правильность всех аргументов.
_Не смешивать с_: маршрутизацией решения, полным исполнимым вызовом.

**Полный вызов инструмента:** выбранная операция с конкретными значениями
всех обязательных аргументов, не требующая их дальнейшего содержательного
дополнения. Полнота сама по себе не означает правильность или допустимость.
_Не смешивать с_: названием операции, планом с незаполненными параметрами.

**Отбор контекста:** выбор доступных документов или фрагментов для решения
при ограниченном текстовом бюджете с учётом релевантности, длины и дублирования.
_Не смешивать с_: генерацией сводки, скрытым удалением истории.

**Фрагмент доказательства:** часть наблюдаемого документа базы знаний,
рассматриваемая как кандидат для включения в контекст с сохранением связи с источником.
_Не смешивать с_: сгенерированной сводкой, полным документом, всем контекстом агента.

**Единица отбора доказательств:** наблюдаемая запись базы знаний целиком либо
её фрагмент, рассматриваемые как один кандидат для включения в контекст.
_Не смешивать с_: обязательной нарезкой каждого документа, итоговым набором контекста.

**Пул наблюдаемых доказательств:** совокупность единиц доказательств из реально
полученного агентом в текущем диалоге KB-текста, включая ранее не выбранные.
_Не смешивать с_: полным корпусом базы знаний, данными других диалогов,
выбранным контекстом или одним входом модели.

**Снимок отбора:** зафиксированные сведения о текущей задаче, доступные единицы
доказательств и бюджет, на которых сравниваются решения об отборе контекста.
_Не смешивать с_: полной скрытой средой, состояниями из разных траекторий.

**Полезность единицы контекста:** оценка пригодности одного наблюдаемого
документа или фрагмента для текущей информационной потребности.
_Не смешивать с_: достаточностью собранного набора, успешностью диалога.

**Риск принятия набора:** оценка возможности ошибочно доверить уже собранному
набору контекста при заданной задаче и бюджете; целевое событие ошибки требует
отдельного определения и проверенных меток.
_Не смешивать с_: полезностью каждого фрагмента, истинной вероятностью успеха
агента или технической невозможностью выполнить отбор.

**Черновик проверки разметки:** незавершённое человеческое решение по конкретной
версии карточки, включая выбранную метку и комментарий.
_Не смешивать с_: подтверждённой проверкой, ответом LLM-разметчика.

**Подтверждённая проверка разметки:** явно завершённое человеком решение по
конкретной версии карточки; последующее исправление сохраняет прежнее решение
в истории. Подтверждение человеком само по себе не гарантирует истинность метки.
_Не смешивать с_: автоматически сохранённым черновиком, безошибочным gold.

**Техническая передача:** обращение к LLM из-за невозможности выполнить компактное
решение, а не из-за оценённого риска ошибки его содержательного результата.
_Не смешивать с_: калиброванной передачей по низкой уверенности, успешным отбором.

**Адаптация модели:** изменение обучаемых параметров модели на данных выбранных
задач для исследования качества, потребности в разметке и переноса.
_Не смешивать с_: обязательным RL, выбором порога маршрутизации.

**Прямое обучение вероятностей:** адаптация модели без RL-компонента, при которой
её вероятностный выход приближается к заданным целевым меткам или распределениям.
В обсуждении инициатора «выравнивание по вероятности» означает именно такое обучение.
_Не смешивать с_: post-hoc калибровкой, подбором порога; совпадение с целевым
распределением само по себе не доказывает калибровку относительно истинного события.
