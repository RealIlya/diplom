# Модели для исследования

Добавлены по поручению инициатора **30.09.2026**. Это отдельный список кандидатов
KEV и Laya; включение не означает обязательного запуска каждой модели.
Приоритеты ниже — предложение по итогам обзора. Практические эксперименты
пока не начаты, ответственные за них ещё не распределены.

Характеристики, источники и уже проверенные ревизии хранятся в
[обзоре моделей](research.md#термины-и-кандидаты-моделей),
а ограничения контекста — в [разделе ресурсов](research.md#ресурсы-и-дообучение-кандидатов).
Перед прогоном закрепить точную ревизию выбранного checkpoint по
[протоколу исследования](research.md#запись-эксперимента).

| Модель | Идентификатор | Предлагаемый приоритет | Что исследовать |
| --- | --- | --- | --- |
| KEV-0.8B | `jaredpalmer/kev-0.8b` | Первый пилот | Качество узкого решения до и после LoRA, задержку и fallback. Ограничение готовой версии на tool-call routing учитывать по обзору. |
| KEV-4B, Qwen3.5 | `jaredpalmer/kev-4b` | Первый пилот | Качество относительно 0.8B, память и задержку на Mac; целесообразность адаптации на GPU. |
| KEV-9B | `jaredpalmer/kev-9b` | После пилота | Оправдывает ли прирост качества дополнительные ресурсы относительно 4B. |
| KEV-27B | `jaredpalmer/kev-27b` (просмотренная v1 `01b81998019be550f0ae858727df49bac9511195`) | Отложен | Верхний ориентир качества, только если меньшие модели оставят существенный исследовательский вопрос; ревизию будущего прогона закрепить заново. |
| KEV-0.6B, Qwen3 | `jaredpalmer/kev-0.6b` | Дополнительное сравнение | Скорость и качество старого компактного поколения относительно 0.8B. |
| KEV-4B, Qwen3 | `jaredpalmer/kev-4b@qwen3` | Справочный | Отличия поколений при одинаковом номинальном размере; не смешивать с актуальной 4B. |
| KEV-8B, Qwen3 | `jaredpalmer/kev-8b` | Справочный | Отличия старого поколения от 9B, если такое сравнение потребуется. |
| KEV-0.5B, прототип | `jaredpalmer/kev-0.5b` | Справочный | Исходный подход; в первый практический набор не включать. |
| Laya English, 421M | `convaiinnovations/laya` | Архитектурное сравнение | Качество компактного encoder на коротком английском состоянии и эффект адаптации. |
| Laya Multilingual, 322M | `convaiinnovations/laya-multilingual` | Архитектурное сравнение | Перенос между языками и качество при увеличении контекста до 8192 токенов. |
| Laya Typed-Decisions, 421M | `convaiinnovations/laya-typed-decisions` | Проверка переноса | Перенос специализации с четырёх исходных workflow на выбранный узел нашего агента. |

Для τ-knowledge предложены KEV-0.8B как дешёвый технический/узкий пилот,
KEV-4B как кандидат на качество после проверки короткого inference и
содержательный дешёвый контроль; готовую 0.8B не считать проверенным
tool-router. Для вспомогательного HotpotQA первой компактной проверкой
остаётся Laya English на короткой паре вопрос–предложение. Эффект адаптации
рассматривать отдельно от выбора узла и базовой архитектуры по
[каноническим контрастам](research.md#кандидаты-на-три-самостоятельных-исследования).
Остальные дешёвые альтернативы перечислены в [общем обзоре](research.md#открытые-кандидаты-для-первого-пилота).
Сравнивать нужно и отдельное решение, и полный успех агента, стоимость и задержку
по [протоколу оценки](research.md#основа-протокола-оценки).
