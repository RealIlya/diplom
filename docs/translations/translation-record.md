## Попытки и преобразования

1. Найдены существующие обзоры и ссылки в wiki; готовых русских переводов
   внутри проекта не обнаружено. Внешний поиск готовых переводов не проводился:
   выбран разрешённый пользователем вариант подготовки новых переводов.
2. Веб-инструмент подтвердил названия, версии и лицензии HTML. Обычный Python
   `urllib` в sandbox не смог разрешить имя хоста. В разрешённом сетевом запуске
   Python остановился из-за отсутствия подходящего локального CA-сертификата.
   Эти попытки не дали исходных файлов. Системный `curl` успешно скачал HTML,
   PDF и внешние SVG с проверкой TLS; отключение проверки сертификатов не
   использовалось.
3. HTML разобран `lxml`, формулы взяты из `math/@alttext`, ссылки на оригинал
   закреплены на версии v1. Временный Markdown подготовлен Pandoc 3.8.3.
   Первая промежуточная конверсия экранировала TeX и поэтому не использована
   как источник формул. Повторная конверсия с временными маркерами сохранила
   TeX буквально. Этот технический сбой не исправлялся догадками о формулах.
4. Перевод создан по полному тексту, а не по прежним выжимкам wiki. Таблицы
   со сложными заголовками дополнительно читаются из HTML. `pdftotext -layout`
   использован для контрольной сверки PDF; предупреждение Poppler о типе
   встроенного шрифта сохранено как наблюдение, извлечение завершилось.
5. Библиография сохраняется в оригинале; примеры программного интерфейса и
   промптов сохраняют исходные идентификаторы. Это явные исключения из перевода
   естественного языка, необходимые для воспроизведения и поиска источников.
6. HTML для чтения собран из перевода с включёнными внутрь файла SVG, стилями
   и MathML, без обращений к языковым API. При первой сборке HTML две таблицы
   SBERT2S1 неверно разбирались: записи вида `68.3$\pm$0.4` позволяли парсеру
   захватить соседние ячейки в одно математическое выражение. Сверка числовых
   ячеек выявила дефект. Изолированные математические символы заменены их
   эквивалентными символами Unicode; формулы с выражениями сохранены в TeX.
   Повторная сборка и сверка прошли. Первый запуск встраивания SVG из корня
   не нашёл относительные пути `assets/`; повторный из каталога переводов
   включил все рисунки без предупреждений. Неудачные сборки не доставляются.
7. Попытка локального HTTP-предпросмотра остановилась на запрете sandbox
   открывать слушающий сокет. Затем встроенный браузер отклонил `file:` URL
   своей политикой разрешённых протоколов. Ограничение не обходилось:
   визуальный контроль готового HTML в браузере не выполнен. Вместо него
   выполнены структурные проверки HTML/MathML, ссылок, встроенных рисунков и
   чисел таблиц. Это ограничение проверки вёрстки, не отказ от полного перевода.

## Итоговые проверки и артефакты

**Содержание.** OpenJev: аннотация, §§1–8, алгоритм из 9 строк, таблицы 1–4,
3 рисунка с подписями, 20 библиографических записей и приложения A–C,
включая две дополнительные таблицы без номеров. SBERT2S1: аннотация, §§1–8,
ограничения, этика, благодарности, 57 библиографических записей и приложения
A–L, таблицы 1–14; рисунки 1–3 и 5–7 включены как SVG, рисунок 4 — как
исходный JSON-пример с переведённой подписью. Библиография сохраняет оригинал.
Нумерация таблиц не менялась, но таблицы OpenJev с двумя наборами задач
разбиты на две читаемые части.

**Смысловая проверка.** Два агента перекрёстно прочитали основной текст другой
статьи после перевода. Особо проверены различие смеси и одного обоснования,
обе составляющие градиента, KL-привязка и две стадии OpenJev; нулевая
инициализация PFR, смещение `(G−1)/G`, нормализация относительно CE,
PG-LOO/Reparam и вывод после температурного масштабирования в SBERT2S1.
Существенных ошибок и пропусков при этой проверке не обнаружено.
Основной агент дополнительно прочитал формализацию и доказательство
приложения C SBERT2S1. Независимая человеческая научная редактура не проводилась.

**Числа.** На этапе перевода проверены строки всех числовых таблиц против
HTML. После сборки основной агент отдельно сравнил мультимножества ячеек,
состоящих из чисел, знаков, интервалов и `±`, в исходном HTML и готовом HTML:
179 ячеек OpenJev и 1099 SBERT2S1 — без отсутствующих значений. Девять
дополнительных чисел OpenJev — введённая колонка номеров строк алгоритма
1–9. Этот автоматический контроль не включает ячейки с текстом или более
сложным TeX и сам по себе не доказывает порядок столбцов; заголовки и строки
дополнительно сверены при переводе. Исходные округлённые числа не пересчитывались.
Машиночитаемая сводка — [verification.json](verification.json).

**Формат.** Обе финальные конверсии Pandoc завершились без предупреждений.
В HTML нет `merror`, остаточных `$` вне кода/формул и внешних таблиц стилей;
269 выражений MathML и 3 встроенных SVG у OpenJev, 396 и 6 у SBERT2S1.
Различие с числом MathML исходника связано в том числе с заменой изолированных
символов `±`, `≤`, `×` на Unicode; число выражений не является метрикой
семантической полноты. Все относительные ссылки Markdown существуют.
Схема SBERT2S1, извлечённая из inline SVG, проверена как XML; её визуальное
представление после извлечения отдельно не подтверждено, текст схемы также
полностью переведён рядом с рисунком. Исходные SVG не требуют внешних ресурсов.

**Документация.** `gitmark.py lint --strict` — чисто (31 документ wiki);
индекс пересобран. `mkdocs build --strict` с временным `site-dir` завершился
успешно. Существующие изменения `site/` не перезаписывались. Обновлены ссылки
в wiki/списке источников и навигация MkDocs.

Команды воспроизведения HTML из корня проекта (Pandoc 3.8.3):

```sh
cd docs/translations
pandoc openjev-rlcd-ru.md --from=markdown+tex_math_dollars --standalone --embed-resources --mathml --toc --toc-depth=3 --metadata lang=ru --metadata title='OpenJev-RLCD — полный русский перевод' --css=reading.css --output openjev-rlcd-ru.html
pandoc sbert2s1-ru.md --from=markdown+tex_math_dollars --standalone --embed-resources --mathml --toc --toc-depth=3 --metadata lang=ru --metadata title='SBERT2S1 — полный русский перевод' --css=reading.css --output sbert2s1-ru.html
```
