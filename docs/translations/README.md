## Как читать

**OpenJev:** сначала §§2–3: что модель генерирует, откуда берутся вероятности и
почему обучение разделено на две стадии. Затем §5.2: что добавляет RL по
сравнению с продолжением обучения из одного и того же checkpoint. После этого
§5.3 и §7: когда рассуждения не помогают и где заканчиваются выводы статьи.
Приложение A содержит оценки градиента, B — параметры, C — сравнение смеси
нескольких запросов с одним запросом.

**SBERT2S1:** §§3.1–3.3 задают интерфейс, четыре способа преобразования энкодера
и сравниваемые цели обучения. §6.3 и приложение C объясняют, что оптимизирует
RLCD с гауссовским шумом логитов; приложение D проверяет оценку градиента.
Полные таблицы находятся в E–I, точный промпт и параметры — в J–L.

Эти два RLCD-рецепта различаются. В OpenJev случайной величиной является
**текстовое обоснование**, после которого считывают распределение ответов.
В исследуемом SBERT2S1 рецепте случайной величиной является **шум логитов**
энкодера. Результат об одном рецепте нельзя автоматически переносить на другой.
Это различие следует из §3 обеих статей, а не из наших экспериментов.

## Короткий словарь

| Термин оригинала | Перевод и смысл |
| --- | --- |
| typed decision | Типизированное решение: распределение по вариантам, разрешённым схемой. Соответствие схеме само по себе не означает правильность ответа. |
| rationale | Обоснование: текст промежуточного рассуждения модели. |
| readout | Считывание распределения ответов из логитов; в OpenJev — после обоснования. |
| logits | Логиты: ненормированные оценки вариантов до softmax. |
| head | Выходная голова: часть модели, преобразующая представления в оценки вариантов. |
| retrieval prior | Априорный сигнал поиска: сходство представлений состояния и варианта в SBERT2S1; это название компонента, а не гарантия байесовской вероятности. |
| proper scoring rule | Собственное правило оценки: математическое ожидание оценки максимально при сообщении истинного распределения. У строго собственного правила максимум единственен. «Собственное» здесь — технический термин. |
| pathwise gradient | Градиент по пути вычислений: дифференцирование результата через вычислительный граф. |
| score-function gradient | Градиент через логарифм плотности: используется член с градиентом логарифма вероятности случайной выборки. Слово score здесь имеет другой смысл, чем оценка ответа. |
| baseline / leave-one-out | Базовый уровень / исключение текущего элемента: способ уменьшить дисперсию оценки градиента; несмещённость зависит от конкретной формулы. |
| calibration / temperature scaling | Калибровка / температурное масштабирование: согласование вероятностей с частотами исходов и один из способов такой коррекции после обучения. |
| selective prediction | Предсказание с возможностью отказа: модель принимает только часть решений, остальные передаёт дальше. |
| coverage / risk / AURC | Охват / риск / площадь под кривой риска и охвата. Охват — доля принятых решений, риск — ошибка на принятом подмножестве; меньшая AURC предпочтительнее. |
| epistemic / aleatoric uncertainty | Эпистемическая / алеаторная неопределённость: в постановке OpenJev — недостаток знания о правильном ответе / разброс исходов, например разногласия разметчиков. |
| ablation | Абляция: контролируемое изменение или исключение компонента для проверки его вклада. |
| seed / checkpoint | Начальное состояние генератора случайных чисел / сохранённое состояние модели. |
| seen / held-out tasks | Знакомые / отложенные задачи: различать отсутствие конкретного примера и отсутствие целого типа задач при обучении. |
