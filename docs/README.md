# Исследовательская wiki

Единый источник проектных решений и ближайших задач — [wiki в GitMark](gitmark/README.md).
Те же Markdown-файлы опубликованы в локальном сайте MkDocs; поиск GitMark,
онтология и команды проверки описаны в [правилах базы знаний](gitmark/ontology.md).

Для направления адаптации System One подготовлены
[подробный исследовательский атлас](gitmark/system-one-atlas.md)
и [21 интерактивная HTML-карта](research-atlas/index.html): общий и операционные
планы, roadmap, архитектура, данные, обучение, измерения и источники.

Выполнен [локальный технический CE-пилот](gitmark/system-one-pilot.md): checkpoint,
split, предварительная разметка и raw dev-результаты сохранены. Научный вывод
пока заблокирован данными и недостатком независимых dev-групп.
