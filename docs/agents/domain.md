# Доменный контекст

В проекте одна общая область контекста. Перед работой читать
[wiki](../README.md), [исследование](../research.md) и
[процесс для агентов](workflow.md); для командных правил —
[docs/team.md](../team.md), для ВКР — [docs/vkr.md](../vkr.md).

`CONTEXT.md` и `docs/adr/` пока отсутствуют. Если они появятся, читать
относящиеся к задаче определения и решения. Не создавать их заранее
и не считать отсутствие решением или неизвестное подтверждённым фактом.

В задачах и документации использовать термины канонических документов.
Если предложение противоречит принятому решению, явно указать конфликт.
