# Презентация для научного руководителя

- [Текущая презентация, 16 слайдов](advisor-presentation.pptx).
  Основной доклад — 18 минут, слайды 1–14; резерв — 15–16.
- [Общий сценарий в Markdown по трём ролям](speaker-notes.md): текст для чтения,
  переходы между участниками, раскрывающиеся пояснения и FAQ в конце.
- Персональные сценарии: [маршрутизация](speaker-notes-role-1-routing.md),
  [отбор документов](speaker-notes-role-2-context.md),
  [адаптация](speaker-notes-role-3-adaptation.md).
- [Исходные заметки в TXT](speaker-notes.txt) соответствуют встроенным заметкам PPTX.
  Для выступления по ролям используйте Markdown. Его 18-минутный хронометраж
  остаётся ориентиром до совместной репетиции, без вопросов.

Роли в сценарии не являются академическим назначением авторов. Markdown следует
текущим слайдам; пояснения закрыты по умолчанию через HTML `details` в GitHub.
Пояснения и FAQ открываются при вопросах и не входят в основной доклад.

Оформление всех слайдов проверено 11.10.2026 на основе v8. Заголовки,
названия блоков, основной текст, формулы, пояснения и нижние подписи используют
тёмный цвет **#182B3B**. Ссылки того же цвета и подчёркнуты; цвета обычных
и посещённых ссылок согласованы во всех темах PPTX. Номера слайдов имеют
единый приглушённый цвет **#5D686E**. В таблицах сохранён белый текст
на тёмной шапке; линии схемы используют акцент **#236F6A**.

Обычный текст — **DejaVu Sans**: заголовок обложки **46 pt**, заголовки слайдов
**33 pt**, заголовки разделов **21 pt**, основной текст и таблицы **18 pt**,
нижние подписи **17 pt**, номера слайдов **13 pt**. Полужирное начертание
используется для заголовков, названий блоков и шапок таблиц.
Формулы остаются редактируемыми уравнениями PowerPoint в **Cambria Math**.
Переменные в формулах и их расшифровке курсивные; знаки и словесные индексы
имеют прямое начертание. Размер математических обозначений в расшифровке — **18 pt**.

Темы исследований, назначения авторам и пригодность стендов остаются
предложениями для обсуждения и пилота. Презентация не подтверждает согласование
руководителем, работающий агент или экспериментальные результаты.
Канонические постановка и состояние — в [исследовании](../../docs/gitmark/research.md)
и [wiki](../../docs/gitmark/README.md).

## Хранение и редактирование

В Git хранится **один текущий PPTX** с постоянным именем, заметки и небольшой
набор текстовых материалов. История изменений хранится средствами Git.
Промежуточные экспорты, превью и архивы помещаются в `artifacts/`, исключённый
из Git. Архив прежних восьми презентаций и их исходников сохранён локально
в `artifacts/advisor-presentation-archive-2026-10-11/`; он не нужен для текущей работы.
Удаление файлов из рабочей копии не удаляет старые бинарные файлы из истории Git.

Редактируемая презентация — основной источник вёрстки. `source/content.json`
хранит содержание, заметки и хронометраж; при содержательных правках нужно
обновлять их вместе с PPTX и `speaker-notes.txt`.
`source/review-style.mjs` согласует цвета существующего текущего PPTX
и выполняет структурную проверку. Это не сборка презентации с нуля и не цепочка,
для которой нужны старые версии. Версии runtime и палитра — в
`source/runtime-versions.json`.

Нужны Artifact Tool **2.8.91**, Node.js, Python ≥3.12, шрифты **DejaVu Sans**,
**Cambria Math** и валидаторы презентаций из среды Codex. Для проверки отображения
используется PowerPoint. Пример для PowerShell в указанной среде, после задания
переменных runtime `CODEX_PRIMARY_RUNTIME_NODE_MODULES`,
`CODEX_PRIMARY_RUNTIME_PYTHON`, `PRESENTATIONS_SKILL_DIR` и пути Node.js
в `CODEX_PRIMARY_RUNTIME_NODE`:

```powershell
$env:DECK_WORK_DIR = 'artifacts/advisor-style-review'
& $env:CODEX_PRIMARY_RUNTIME_NODE presentations/advisor/source/review-style.mjs
```

Результат сохраняется в `output/`, диагностика — в `.build/` указанного каталога.
Для повторного запуска задайте новый `DECK_WORK_DIR`: финализатор не перезаписывает
существующий результат. После просмотра замените текущий PPTX проверенным файлом,
обновите [SHA256SUMS](SHA256SUMS) для всех файлов этого каталога и выполните:

```sh
python scripts/check_presentations.py
python -m unittest discover -s tests -p test_presentations.py -v
```

Checker проверяет единственный текущий PPTX, ZIP/XML, внутренние ссылки, число
слайдов, portable notes, хронометраж и полный набор SHA-256. Он не заменяет
визуальный просмотр. Все 16 слайдов просмотрены по рендеру PowerPoint;
проверены границы 193 текстовых блоков. Текст, математические записи,
положения объектов, изображения и внешние ссылки сохранены относительно v8.
13.10.2026 пути к проектной wiki в заметках обновлены после её переноса
в `docs/gitmark/`; тексты заметок и видимые слайды сохранены.
Регрессионные проверки защищают постановку задачи и стоимость успеха, включая
учёт всех попыток и случай отсутствия успехов. Файлы блокировки PowerPoint
`~$*.pptx` исключены из Git, проверок и контрольных сумм.
Текстовые материалы закреплены с LF для стабильных контрольных сумм в Windows.
