# System One в языковых агентах

Исследовательский репозиторий для бакалаврских ВКР ФПМИ НГТУ:
**02.03.03 «Математическое обеспечение и администрирование информационных систем»**, кафедра ТПИ, защита в 2027 году.

Исследуем, при каких условиях модели типизированных вероятностных решений
(открытые кандидаты KEV для τ-knowledge и Laya для HotpotQA) полезны внутри AI-agent pipeline и как их применение
влияет на итоговое качество, стоимость и задержку.

**Текущий этап:** подготовлена [архитектура v0.3 с программой экспериментов](docs/architecture.md).
Исследуем выбор tools, поиск и использование знаний с открытыми моделями;
включён τ-knowledge, HotpotQA предложен как вспомогательный RAG-стенд.
Версии данных и условия предстоит проверить пилотом; реализации и результатов
экспериментов пока нет. Тема не утверждена руководителем.

## Состояние репозитория

Wiki хранится в `docs/` и версионируется вместе с проектом. Это единый источник
проектных решений для людей и агентов; разные маршруты чтения не создают копий фактов.

Начальный каркас содержит документацию и правила Git. Репозиторий размещён на
[GitHub](https://github.com/Nikita-812/diplom); лицензия не выбрана. Код, данные,
тексты ВКР и статей добавляются по мере работы; инструкции запуска появятся
вместе с первым работающим экспериментом.

## Локальная wiki

Сайт собирается из файлов `docs/`; исходный Markdown остаётся доступен напрямую.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-docs.txt
.venv/bin/mkdocs serve
```

Предпросмотр открывается по адресу <http://127.0.0.1:8000/>. Для проверки перед review:

```sh
.venv/bin/mkdocs build --strict
```

Сборка обновляет хранящийся в Git каталог `site/`. Размещение сайта на хостинге
отдельно не настроено.

GitHub Actions проверяет Markdown, YAML, регрессионные тесты импортированного
инструмента, целостность презентаций и соответствие хранящегося в Git сайта
строгой сборке wiki для каждого pull request и после изменений в `main`.
CI не запускает научные эксперименты и не использует платные API.
